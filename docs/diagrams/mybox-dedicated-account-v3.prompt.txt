Style reference: mybox-concept-v4.png

New README diagram in the style of the supplied figure, using it only as a guide for cream paper, fine charcoal ink and serif lettering. Entirely different composition. Draw just THREE things: the mybox command-line program, the MyBox service and the box files. One horizontal visual sentence, left to right: a terminal window with “> mybox” inside it, a thin arrow to “MyBox service” inside a simple modest rounded rectangle, a thin connector from the service to a small recognisable folder marked “Box files”. The arrow from the terminal must terminate on the service; there is no terminal-to-folder line. Use enclosures to show which account runs or owns each thing: enclose only the terminal in a light outline labeled “Your Mac account”; enclose BOTH the service and folder together in ONE wider outline labeled “macOS user _mybox” with the underscore visible. Give both account labels equal size and position, neatly set into the top border like a technical schematic. Two account frames, three objects total, with all three centers aligned horizontally. Both enclosures at the same height. Keep “Box files” easily legible, inside or just below its folder. Wide compact landscape, quiet warm ivory background, lightly textured paper, flat 2D linework, muted sage-black ink, consistent clean lettering, generous space around the shapes. No headings, additional wording, operating system lists, captions, legends, section dividers, shields, locks, keys, fingerprints, badges, crossed lines or decoration. Use exactly and only the five quoted labels.
