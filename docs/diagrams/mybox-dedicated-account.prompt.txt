Style reference: mybox-outside-access-v13.png

Draw a NEW companion README figure about who owns the MyBox disk. Use the reference only for its restrained antique technical manual style: cream paper, fine black ink lines, serif type, small flat pictograms, muted red X. Wide compact figure. Design a single horizontal path with two equally prominent side-by-side account panels. LEFT panel heading “Your Mac account”, with a simple terminal icon inside. RIGHT panel heading “Dedicated macOS user” with the account name “_mybox” directly below in equally legible type. A small flat top-view hard drive icon (mechanical disk platter and arm) sits well inside the RIGHT panel, with the label “MyBox virtual disk” immediately above the icon. A dashed line comes from the terminal in the left panel and STOPS at a muted-red X on the left edge of the right panel. Label the line “Direct disk access” so the X clearly means that regular user cannot open this disk directly. Separate the panels enough to fit this label easily. The nesting of the disk inside the _mybox account clearly conveys ownership. Use only the specified text once each. No title, footer, large decorations, network, Touch ID or approval arrows. Render all words and the leading underscore exactly.
